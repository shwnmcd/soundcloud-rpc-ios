# CloudWave

An ad-free, cross-platform SoundCloud player with **Discord Rich Presence**, **Worldwide Group Jam**, **Multiplayer Chess & 21 Blackjack**, **Custom Themes**, **Vinyl Record Player**, and a **Hardware VFD Spectrum Visualizer**.

## Downloads

Grab the latest builds from the **[Actions](../../actions)** tab:

| Platform | Artifact | Install |
| --- | --- | --- |
| **Windows** | `CloudWave-Windows` (`CloudWave.exe`) | Unzip and run `CloudWave.exe` |
| **iOS / iPadOS** | `CloudWave-iOS` (`CloudWave.ipa`) | Sideload with **AltStore** |
| **Android** | `CloudWave-Android` (`CloudWave.apk`) | Install `CloudWave.apk` directly |

## Features

- **Zero Ads & Two-Way Sync:** Stream directly via SoundCloud API v2 with live Like, Follow, and Playlist sync.
- **Discord Rich Presence (Windows):** Native local Discord IPC with live timestamps, album art, and Jam status.
- **Worldwide Group Jam:** Listen in real-time sync across Windows, iOS, and Android with Host-Only or Shared controls.
- **Jam Mini-Games:** Play live multiplayer **Chess** (Windows ↔ iOS) or **21 / Blackjack** solo or in a Jam.
- **Themes & Visuals:** Dark, Light, Midnight OLED, 6 accent colors, Rotating Vinyl Player, and a customizable VFD Spectrum Visualizer.
